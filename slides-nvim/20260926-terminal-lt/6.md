# 私の毎日の開発の始まり (2)

`terminal_registry#start`関数:

- 指定したコマンドでターミナルを起動、名前を割り当てる

```vim
call terminal_registry#start("pnpm run dev", { "id": "server" })
"                                              ^^^^^^^^^^^^^^
"                                             ここで名前を指定
```

- `id`を指定しない場合は、コマンド名がそのまま名前になる

```vim
call terminal_registry#start("bash")
"                            ^^^^^^
"                      この場合は "bash" が名前になる
```
